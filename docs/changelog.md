# 更新记录

[文档中心](README.md) · [下载版本](https://github.com/Qwerto107/QPix/releases) · [发布流程](releasing.md)

## v0.4.0 · 2026-10-24

- 系统设置增加限频策略，支持调整五类现有限频规则的启停、请求次数和时间窗口，保存后立即生效。
- 将上传压缩和访问控制并入系统设置，按分类展示，切换时保留未保存的输入。
- 修复手动拖选 Token 文本并在弹窗外松开时误关闭弹窗的问题。
- 分享列表仅管理已有记录，创建分享统一从图库图片或图片详情进入，移除搜索和选图流程。
- 系统设置使用紧凑页签，修复通用输入框样式覆盖画质滑条的问题；更新使用说明、API 与界面预览。

## v0.3.1 · 2026-10-23

- 相册访问设置展示只读相册 ID，支持一键复制，便于填写 API 的 album_id 参数。

## v0.3.0 · 2026-10-23

- 增加 BMP、TIFF、ICO、AVIF、HEIC／HEIF、静态 JXL 和 SVG 上传，以及动画 WebP 原文件保存。
- 静态位图支持原格式压缩和转 WebP，保留透明度；多尺寸 ICO 原格式压缩保留各尺寸，转 WebP 取最大尺寸。
- 为浏览器兼容性有限的格式生成独立预览，预览沿用原图权限、分享校验和删除清理流程。
- 上传默认勾选随机文件名，可取消并保留原名；API 提供 random_name 字段。

## v0.2.0 · 2026-10-23

### 新增

- 浏览器控制台显示绿色版本标签、8 位构建提交哈希和版权署名。

### 修复与安全

- 统一 SQLite 新记录和历史时间，修复非 UTC 时区下的游标分页及今日统计。
- 临时存储故障返回明确的 500，分别处理上传格式和大小错误；Compose 临时空间上限调整为 1 GiB。
- 写入前重新检查权限，存储 I/O、请求接收、密码计算和文件清理移出全局锁。
- 分离认证限流，分享创建按账号限流；未知账号登录执行假哈希校验，应急跳过网络规则时输出警告。

### 性能优化

- 公开直链支持私有缓存与 ETag，304 不读取存储对象；受限图片及分享禁止缓存。
- 合并资源查询，Token 使用时间按分钟更新；图库、分享及 Token 接入游标分页。
- 流式保存原图，优化缩略图格式、原图复用及 PNG 量化；图片容量改为事务计数。
- 补建列表与存储索引，PostgreSQL 检测手动安装的 pg_trgm 并补建搜索索引；PostgreSQL、MySQL 配额采用用户行锁。
- SQLite 重建连接恢复 PRAGMA，保留 FULL 刷盘，增加统计维护及 PASSIVE 检查点；MySQL 优化连接回收及预编译缓存，过期会话分批清理。

### 文档

- 按使用、部署和开发分组导航，合并重复说明，集中图片处理实现与运行维护配置。
- 同步代理安全配置、数据库运维、内存及上传临时空间说明。

已有部署升级前备份数据库、全部图片存储和原主密钥，并同步 Compose 的临时空间上限。SQLite 历史时间规范化及新索引构建可能增加首次启动耗时，步骤见 [升级与回退](deployment.md#升级与回退)。

## v0.1.2 · 2026-10-22

- 修复 PostgreSQL 初始化时 Token 权限迁移查询未引用保留字列名，导致服务无法启动的问题；保留已有数据。
- 数据库连接失败保留驱动具体错误，迁移失败标明数据库类型；记录失败 SQL、调用位置和耗时，SQL 参数保持占位符。

## v0.1.1 · 2026-10-22

- 完整程序内嵌前端，增加 Linux amd64、arm64、armv6、armv5、loong64，Windows amd64 和 macOS arm64 二进制打包。
- 统一镜像扩展为五种 Linux 架构，使用 `scratch` 运行层和程序自身健康检查；CI 复用打包程序，不重复构建前后端。
- Release 先创建草稿，七份压缩包及七份 SHA-256 文件上传、核对完整后公开，提供可选竞态与简单容器健康检查。
- 重整 README 与文档导航，同步部署、权限、访问规则、压缩、API 及使用说明，补充实际界面预览。
- 容器配置统一为根目录 `docker-compose.yml`，支持直接下载部署，数据挂载到运行目录的 `./data`。

二进制附件与统一镜像由本版标签的 Actions 工作流构建并发布；历史 `v0.1.0` 标签不会自动获得这些二进制附件。

## v0.1.0 · 2026-10-22

首版代码标签，提交 [`f3130c6`](https://github.com/Qwerto107/QPix/commit/f3130c6)。镜像和 Release 的实际发布状态以对应 Actions 运行结果为准。

- Go + GORM 后端、Vue + TypeScript 前端，支持 SQLite、PostgreSQL、MySQL，本地与 S3 多存储。
- 统一登录、管理员创建账号、个人与全站管理分离，每用户容量及单张限制，支持角色调整、账号停用和受约束的删除。
- 单层相册、可更换默认相册、访客直链权限及独立 Referer；删除相册时明确转移图片或连同删除。
- 多图上传、原格式／WebP 压缩、画质滑块和透明度保留；图库三种视图、图片缩放及批量整理。
- 单图密码／期限分享、撤销与记录删除；个人 Token 按相册授权，支持永久、自定义期限和使用记录。
- 站点域名、可信代理、HTTPS Cookie、上传大小／像素上限迁入后台，移除对应运行环境变量读取。
- 统一 Docker 镜像及版本标签触发的 GitHub Actions Release。
