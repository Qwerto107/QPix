推荐使用 Docker Compose。直接运行程序时，选择二进制部署；两种方式的数据库、后台设置和运维说明统一放在部署指南。

| 要做的事 | 文档 |
| --- | --- |
| 用 Docker 安装，配置数据库、HTTPS 和存储 | [部署指南](deployment.md) |

## 默认地址

| 运行方式 | 地址 | 命令执行位置 |
| --- | --- | --- |
| Docker Compose | <http://127.0.0.1:7979> | 自建运行目录，内含 `docker-compose.yml` 和 `.env` |
| 发行程序 | <http://127.0.0.1:8080> | 解压后的程序目录 |
| 本地前端开发 | <http://127.0.0.1:5173> | 源码仓库，前后端分别启动 |

容器和发行程序均包含前端。平台以对应版本的 Release 附件为准，界面预览见 [项目首页](../README.md#界面一览)。
