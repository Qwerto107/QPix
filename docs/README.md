# 文档中心

[项目首页](../README.md) · [下载版本](https://github.com/Qwerto107/QPix/releases)

QPix 提供内嵌前端的完整程序与统一镜像，按使用场景选择文档：

| 文档 | 内容 |
| --- | --- |
| [使用指南](usage.md) | 图库、相册、上传、图片预览、分享与账号安全 |
| [部署指南](deployment.md) | Docker、数据库、启动参数、后台设置、反向代理与升级 |
| [二进制部署](binary.md) | Linux、Windows、macOS 程序、校验、启动及数据目录 |
| [API 参考](api.md) | 登录会话、个人 Token、接口、参数与图片网关 |
| [开发指南](development.md) | 分离开发、完整程序构建、现有检查与目录结构 |
| [发布流程](releasing.md) | 七平台二进制、五架构镜像、标签及自动 Release |
| [更新记录](changelog.md) | 版本变化及尚未发布的改动 |

默认容器入口为 <http://127.0.0.1:7979>，二进制入口为 <http://127.0.0.1:8080>，Vite 开发入口为 <http://127.0.0.1:5173>。镜像部署命令在自建运行目录执行，源码构建命令在仓库根目录执行，除非对应文档另有说明。

界面截图位于 `docs/assets/`，使用独立演示数据截取实际界面。文档中的平台列表描述当前发布流程，具体版本可下载内容以 Release 附件为准。
