# 使用指南

[文档中心](README.md) · [部署指南](deployment.md) · [API 参考](api.md)

## 登录与个人空间

管理员与普通用户使用同一登录页，只输入用户名和密码。注册关闭，由管理员创建账号；管理员也有自己的“我的图库”“我的分享”“我的 Token”，系统管理入口单独展示。

通过右上角账号菜单打开“账号安全”，修改本人密码时填写当前密码并重复输入新密码。修改后需重新登录，个人 Token 保持有效；管理员停用账号会撤销该账号 Token。

## 相册与图库

“我的图库”首先展示自己的单层相册。每个账号自动创建默认相册，点击相册进入图片；可切换大图标、小图标、详细信息，并搜索、排序和分页。

- 相册右侧“更多操作”包含访问设置、重命名、设为默认及删除。
- 当前默认相册不能直接删除，先将另一个相册设为默认。
- 删除普通相册时，明确选择转移到另一个本人相册，或连同图片删除。转移后权限与 Referer 不同时会提示规则变化。
- 图片可多选，批量复制链接、移动或删除；详细列表也提供单张删除按钮。
- 普通用户不显示他人授权相册，没有“共享给我”入口；管理员在系统管理中按上传人查看全站资源。

新相册默认允许访客通过已知图片直链查看，不提供公开相册目录。关闭访客访问后，界面显示“仅用户访问”；私有直链仅本人／管理员会话，或有对应相册读取权限的个人 Token 可访问。其他普通账号不会因此获得浏览权。

## 上传与压缩

支持选择、拖拽、剪贴板粘贴和多图上传，最多两个并发。进入相册后点击上传会预选该相册；未选择时上传到本人的当前默认相册。

上传前可选择存储、压缩方式和画质。画质 1–100，数值越高画质越好，不是体积缩减百分比；原文件模式不应用画质。透明 PNG 仍可压缩，PNG 与 WebP 处理保留透明通道。只有结果变小时才采用，处理失败或超过压缩限制则保留原文件。

每张图片入队时固定相册、存储和压缩参数，失败重试沿用原参数。成功后可单独复制每张图片链接，批量复制时每张一条；支持直链、Markdown 和 HTML。

### 压缩细节

| 方式 | 行为 |
| --- | --- |
| 保留原文件 | 不改字节，不应用画质 |
| 原格式压缩 | JPEG／静态 WebP 按画质重新编码；PNG 量化 RGB 色阶并保留逐像素 alpha |
| 转换 WebP | 有损 WebP，按画质编码，保留透明度；实际格式与链接后缀改变，显示名称保留 |

默认保留原文件，默认画质 82，上传时可覆盖。PNG 使用纯 Go 色阶量化与 DEFLATE，画质 100 保留 8 位完整色阶；不调用第三方压缩服务。JPEG 重新编码前校正 EXIF 方向，压缩结果不携带原 EXIF／XMP。

GIF、APNG、16 位 PNG 和需要保留特殊色彩／元数据的文件不重编码；动画 WebP 不在支持范围。压缩最多处理 400 万像素，与服务器上传像素上限独立。仅采用更小的结果，失败、无收益或超限保留原文件；采用处理结果后不额外备份原文件。缩略图独立生成最长边 480px 的 PNG，GIF 使用首帧。

## 图片详情

点击图片打开详情，可查看格式、尺寸、大小、上传信息和所属相册。可管理时支持重命名、移动及删除。

预览工具栏提供放大、缩小、100% 原始大小和适应窗口；滚轮缩放，放大后拖动。预览区域获得焦点时可用 `+`／`-` 缩放、方向键移动、`0` 适应窗口、`1` 原始大小，最大放大至 800%。

## 直链与单图分享

直链适合嵌入博客、Markdown 或 HTML，遵循相册访客开关、图片 IP 白名单及有效 Referer 策略。“继承全局”使用访问控制的“图片直链”规则，默认未启用 Referer 限制。

需要独立授权时，在图片上点击“分享”：目标已确定，只需填写可选密码及有效期。通过分享列表单独创建时，才搜索和选择图片。分享默认永久有效，可选小时、天数或自定义日期；日期使用设备本地时间。

“我的分享”只管理本人创建的记录，可重新复制、撤销，并删除已撤销记录。到期或撤销后链接失效，删除分享记录不删除原图片；分享不受相册 Referer 限制，仍检查密码、期限和撤销状态。分享能力仅面向单张图片。

## 个人 Token

在“我的 Token”创建个人 API 凭据，选择全部本人相册统一授权，或对指定相册分别设置读取、上传、修改、删除、相册管理、分享管理权限。默认 90 天，可选永久或自定义期限。

完整 Token 只在创建时显示一次，请及时保存。列表显示授权范围、到期日期／剩余时间、创建时间和上次使用；撤销后可永久删除记录，已到期但未撤销的 Token 也须先撤销。

管理员的个人 Token 也只有本人相册权限。系统管理的“Token 管理”用于管理全体用户凭据，只允许管理员登录会话操作；个人 Token 不能创建其他 Token 或执行系统管理。脚本请求见 [API 参考](api.md)。

### 相册授权与操作边界

- 全部本人相册：统一权限，包含后续新建的本人相册。
- 指定相册：最多 200 个本人相册，逐相册选择操作权限。不能访问他人相册，公开直链也不会扩大携带 Token 请求的授权。
- 未提交相册时，当前默认相册仍须具备上传权限；移动图片要求源相册修改权限及目标相册上传权限。
- 指定相册模式不能新建相册；连同图片删除还需图片删除权限。分享管理仅限已授权相册中的本人图片，撤销 Token 不会撤销既有分享链接。
- 权限变更对后续请求即时生效。Token 到期、撤销或所属账号停用后不能使用；不允许借 Token 创建其他凭据、改密或管理系统。

## 有效期

Token 与图片分享共用永久、1／6／12 小时、1／3／7／14／30／90／180／365 天及自定义日期。固定期限从本次保存时刻计算；自定义控件支持年月、日历、24 小时时分与快捷日期，使用设备本地时间，后端存储 UTC。自定义日期必须晚于当前时刻，编辑未改变时刻时保留原秒数。

## 管理后台

| 入口 | 用途 |
| --- | --- |
| 图片／分享／Token 管理 | 查看全站资源，包含创建人、身份及时间信息 |
| 用户管理 | 创建账号、角色、启停、配额、重置密码与受约束的删除 |
| 存储管理 | 本地／S3 配置、连接测试、默认存储和停用 |
| 图片处理 | 新上传使用的默认压缩方式与画质 |
| 访问控制 | 直接展开管理端、上传接口及图片直链规则，各自保存 |
| 系统设置 | 站点和图片域名、可信代理、HTTPS Cookie、上传大小及像素限制 |

调整服务器限制不会删除已有图片。用户单张限制为 0 时跟随服务器，实际取用户与服务器两者较小值；容量为 0 表示不限累计容量。用量按主文件实际保存大小统计，包含待删除图片，不计缩略图和数据库；上传前按原文件大小预占，完成后结算，失败释放。

管理员修改账号角色会使目标登录会话失效，个人 Token 不获得系统管理权限。不能更改自己的角色、停用或删除当前账号，必须保留启用的管理员。删除用户前先清理其全部图片（含待删除）和分享记录（含已撤销）；成功后清理空相册、会话、Token 与容量预占。

图片删除后直链及关联分享立即失效，物理清理失败时由后台重试，完成后释放容量；没有回收站。单图分享随图片移动继续存在，不改变上传人及容量归属，也不受目标相册 Referer 限制。
