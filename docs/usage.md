## 登录与账号安全

管理员和普通用户使用同一登录页。注册关闭，账号由管理员创建。

在右上角账号菜单打开“账号安全”。修改密码时填写当前密码，并重复输入新密码。密码须非空，最多 72 字节，不强制最短长度或复杂度。修改后需要重新登录，个人 Token 保持有效。

## 相册与图库

“我的图库”按单层相册展示。每个账号都有默认相册，未选择相册时，图片上传到当前默认相册。点击相册后，可搜索、排序，并切换大图标、小图标或详细信息视图。

相册的“更多操作”提供重命名、访问设置、设为默认和删除。当前默认相册需要先更换，才能删除。删除普通相册时，可以选择：

- 将图片转入另一个本人相册。目标相册权限或 Referer 策略不同时，界面提示访问规则变化。
- 连同图片删除。图片删除后没有回收站。

图片支持多选、批量复制链接、移动和删除，详细列表也可单张删除。每个人管理自己的相册；管理员可在系统管理中按上传人查看和管理全站资源。

### 相册访问权限

在相册的“更多操作 → 访问设置”中，可查看并复制相册 ID，用于 API 的 `album_id` 参数。

新相册默认允许访客凭已知图片直链访问。QPix 不提供公开相册目录、“共享给我”或相册分享入口。

关闭访客访问后，界面显示“仅用户访问”。此时直链仅限图片所有者、管理员登录会话，或具有该相册读取权限的个人 Token。其他普通账号不会获得访问权。

Referer 可以选择继承全局、自定义白名单或不限制。“继承全局”使用后台的图片直链规则，初始默认不限制来源。规则范围见 [访问控制](deployment.md#访问控制)。

## 上传图片

支持文件选择、拖拽、剪贴板粘贴和多图队列，网页最多同时上传两张。进入相册后点击上传，会预选该相册。

上传前选择存储、压缩方式、画质和随机文件名。随机文件名默认勾选，使用随机 ID 和实际格式后缀；取消后保留原文件名。每张图片入队时固定这些参数，失败重试沿用原参数。

上传成功后，每张图片可单独复制链接；批量复制时每张一条，支持直链、Markdown 和 HTML。显示名称可以重复，存储对象和直链始终使用独立的随机 ID，不会覆盖同名图片。

### 压缩细节

| 方式 | 行为 |
| --- | --- |
| 保留原文件 | 不改变文件字节，不应用画质值 |
| 原格式压缩 | 按画质重编码，保留格式；不同格式的编码方式见下表 |
| 转换 WebP | 转为有损 WebP，保留透明度；实际格式和链接后缀随之改变 |

默认保留原文件，默认画质为 82。画质可选 1～100，数值越高，画质越好；它不表示体积缩减百分比。

| 格式 | 原格式压缩 | 转 WebP |
| --- | --- | --- |
| JPEG、静态 WebP、AVIF、HEIC／HEIF、静态 JXL | 按画质重编码 | 支持 |
| PNG | 减少 RGB 色阶，保留 alpha | 支持 |
| BMP | 不透明图片减少颜色并使用索引编码；透明图片保留 RGBA | 支持 |
| 单页 TIFF | 减少 RGB 色阶，使用 DEFLATE | 支持 |
| ICO | 各尺寸分别减少 RGB 色阶，保留全部尺寸与透明度 | 使用最大尺寸 |
| GIF、APNG、动画 WebP、AVIF／HEIF 序列、多页 TIFF、SVG | 保留原文件 | 保留原文件 |

压缩最多处理 400 万像素，与服务器上传像素上限独立。16 位、CMYK 和已识别出需要保留特殊色彩或元数据的图片跳过重编码。JPEG 重编码前校正 EXIF 方向，结果不保留原 EXIF、XMP。`.jpeg`、`.tif`、`.heif` 等别名按实际格式规范直链后缀。

SVG 拒绝脚本、事件属性、指向外部的 href 和 DTD，最大 4 MiB。ICO 最大 8 MiB、64 个尺寸。PSD、AI、RAW、JP2／J2K 和动画 JXL 不支持上传。HEIF 仅支持当前 HEVC 解码器可读的内容，部分编码变体可能无法解码。

只有结果更小时才采用。失败、超限或没有体积收益时，保留原文件。**采用压缩结果后，不额外保存原文件副本。**

PNG 量化、缩略图生成及并发处理见 [开发指南](development.md#图片处理)。

## 图片详情

点击图片查看格式、尺寸、大小、上传信息和所属相册。具有管理权限时，可重命名、移动或删除。

BMP、TIFF、HEIC、JXL 等格式生成浏览器可读的独立预览，原文件直链保留实际格式。详情页可以复制预览链接或下载原文件；独立预览最长边为 1920 px，100% 显示的是预览自身像素。SVG 使用浏览器图片上下文预览，直接打开原文件链接时下载。复杂 SVG 可能没有缩略图。

预览支持滚轮缩放、放大后拖动、100% 原始大小和适应窗口，最大放大至 800%。预览区域获得焦点后，可用 `+`、`-` 缩放，方向键移动，`0` 适应窗口，`1` 查看原始大小。

## 直链与单图分享

| 链接 | 用途 | 访问规则 |
| --- | --- | --- |
| 图片直链 | 嵌入博客、Markdown 或 HTML | 相册访客权限、图片 IP 白名单和有效 Referer 策略 |
| 单图分享 | 通过独立链接提供一张图片 | 可设置密码、到期时间和撤销；不应用直链的 IP、Referer 规则 |

在图片上点击“分享”，直接填写可选密码和有效期。在“我的分享”主动创建时，需要先搜索并选择图片。分享默认永久有效。

分享列表可复制链接、撤销分享，并删除已撤销记录。到期或撤销后，链接失效；删除分享记录不删除图片。图片删除后，关联分享也失效。图片移动不会撤销既有分享，已经下载的副本无法收回。

## 个人 Token

在“我的 Token”创建脚本使用的 API 凭据。完整 Token 只在创建时显示一次，请及时保存。请求示例见 [API 参考](api.md#用户-api-token)。

| 授权方式 | 范围 |
| --- | --- |
| 全部本人相册 | 统一设置权限，包含后续新建的本人相册 |
| 指定相册 | 最多选择 200 个本人相册，分别设置权限 |

权限包括读取、上传、修改、删除、相册管理和分享管理。默认相册也需要明确获得上传权限。移动图片需要源相册的修改权限和目标相册的上传权限；指定相册模式不能新建相册。连同图片删除相册，还需图片删除权限。

管理员的个人 Token 同样只操作本人授权相册。Token 不能管理账号、修改密码、创建其他 Token 或操作系统设置。撤销 Token 不会撤销它已创建的分享。

列表展示权限、有效期、创建时间和上次使用。上次使用时间最多每分钟更新一次。撤销后立即停止接受新请求，已到期的 Token 也需要先撤销，才能永久删除记录。

## 有效期

Token 默认 90 天，分享默认永久。两者都可选择永久、1／6／12 小时、1／3／7／14／30／90／180／365 天，或自定义日期。

固定期限从保存时刻计算。自定义日期使用设备本地时间，必须晚于当前时刻；后端保存 UTC 时间。编辑时未改变日期，会保留原秒数。

## 管理后台

| 入口 | 用途 |
| --- | --- |
| 图片、分享、Token 管理 | 管理全站资源，查看创建人、身份和时间 |
| 用户管理 | 创建账号，调整角色、启停、配额和密码，删除已清理的账号 |
| 存储管理 | 添加本地或 S3 存储，测试连接，设为默认或停用；见 [存储配置](deployment.md#多存储与主密钥) |
| 图片处理 | 设置新上传默认使用的压缩方式与画质 |
| 访问控制 | 分别配置管理端、上传接口和图片直链规则；见 [访问控制](deployment.md#访问控制) |
| 系统设置 | 配置站点、图片域名、代理、HTTPS Cookie 和上传限制；见 [后台运行设置](deployment.md#后台运行设置) |

### 容量与上传限制

用户容量为 0 表示不限累计容量。用户单张限制为 0 时跟随服务器；设置后取用户与服务器上限中的较小值。调低限制不会删除已有图片。

容量按主文件实际保存大小统计，不计预览图、缩略图和数据库。待删除图片仍占用容量，文件清理成功后释放。

### 用户管理

修改角色会使目标账号重新登录；停用账号会使其 Token 失效。当前账号不能修改自己的角色、停用或删除自己，系统必须保留启用的管理员。

删除用户前，先清理其全部图片及分享记录，包括待删除图片和已撤销分享。删除成功后，空相册、会话、Token 和容量预占一并清理。
