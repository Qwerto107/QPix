# 账号、相册与分享

## 个人空间与系统管理

注册关闭，由管理员创建普通账号。所有账号使用同一登录入口，后端从数据库识别角色。管理员同样拥有个人空间，默认列表和统计只包含本人资源。

- “我的图库”“我的分享”“我的 Token”按账号隔离，管理员同样具有个人空间。
- 管理员另有全站图片、分享与 Token 管理，以及用户、存储、处理和访问控制设置。
- `GET /images`、`/albums`、`/shares`、`/tokens`、`/stats` 默认范围为本人；管理员显式提交 `scope=all` 查看全站，普通用户提交此参数返回 403。
- 普通用户只能修改或删除本人资源。图片直链公开不代表其他账号可以在图库中发现或管理它。
- 系统不提供访客图库、相册账号授权、共享给我或相册分享。

## 相册与默认上传

每个账号自动创建“默认相册”，允许将自己的其他相册设为默认。采用单层相册，个人图库首先展示相册，进入后浏览图片，支持大图标、小图标及详细信息。

网页未选相册、脚本或 Token 未提交 `album_id` 时，后端使用上传者当前默认相册。在相册内点击上传时预选该相册。管理员上传同样归入本人的相册；管理已有图片时可在实际上传者的相册之间整理，不转移上传者身份和容量归属。

- 当前默认相册不能直接删除，返回 409；须先指定另一个默认相册。
- 删除普通相册必须明确选择 `move` 并指定该账号的其他相册，或选择 `delete` 连同图片删除。
- 转移保留图片和直链，之后立即应用目标相册的访问策略；界面在策略不同时提示变化。
- 连同图片删除先将图片标记为待删除，使原图、缩略图与分享立即失效，再清理文件；存储失败由后台重试，完成物理删除后释放用量。

新建相册默认允许访客通过已知图片直链访问，不提供相册浏览入口。所有者和管理员可关闭该项，此后普通直链仅本人和管理员可访问；有效的单图分享仍授予独立只读权限。

## 相册 Referer

相册支持继承全局、自定义域名白名单、不限制 Referer。自定义规则支持域名、`*.example.com` 及单独控制空 Referer；通配符不包含主域名。

相册仅覆盖图片资源的全局 Referer 部分，全局 IP 规则始终有效。仅原图和缩略图直链检查相册策略，分享内容及解锁不受相册 Referer 影响，且检查先于读取文件及 ETag / 304。移动图片后立即使用目标相册策略，不改变单图分享目标。

## 配额

- `quota_bytes = 0`：不限累计容量。
- `max_file_bytes = 0`：单张跟随服务器；实际取用户和服务器上限较小者，限制上传原文件。
- 容量计入实际上传人，按主文件保存大小累计，包含待删除记录，不包括缩略图、数据库和文件系统开销。
- 上传前按原文件大小预占，压缩后按实际保存大小结算；失败释放预占，降低配额不删除图片。

容量预占及最终图片入库由事务和单实例锁协调。当前仅支持一个 Go 服务实例。

## 单图分享

所有登录用户可为自己的单张图片创建分享，管理员可为全站图片创建分享；分享归创建人所有。“我的分享”只展示本人创建的记录，管理员通过全站管理查看与撤销所有人的分享。

密码可选，最多 72 字节，不强制最短长度或复杂度，保存 bcrypt 哈希。到期时间可选，留空永久；界面使用设备本地时间，后端统一 UTC。密码解锁 Cookie 最长 24 小时且不超过到期时间。

分享使用高熵随机令牌，哈希查找、主密钥加密保存以便再次复制。分享页面通过 `/si/<token>/<file>` 获取图片，不输出普通直链。撤销、到期或目标删除后立即失效，已解锁 Cookie 和 ETag 不能绕过检查。单图分享随图片移动持续存在，不受目标相册 Referer 策略限制。

## 用户 Token 与账号安全

所有账号均可创建和使用个人 API Token，管理员的个人 Token 同样仅限本人授权相册，不具备全站管理权限。个人空间的“我的 Token”管理自己的凭据；系统管理的“Token 管理”可查看、修改全体用户 Token 的授权及有效期，也可撤销。Token 管理接口始终只接受登录会话，Token 本身不能派生或管理其他凭据，也不能调用账号、改密、用户管理、存储或系统设置接口。

撤销后默认保留记录；本人或管理员可进一步永久删除已撤销的 Token 记录，界面要求二次确认。不允许直接删除未撤销的 Token，已到期但未撤销的记录也须先撤销。删除记录不影响图片、分享或其他凭据。

支持两种授权范围：

- 全部本人相册：统一选择操作权限，包含之后新建的本人相册。
- 指定相册：选择 1–200 个本人相册，分别授权读取、上传、修改、删除、管理相册、管理分享。每个授权范围至少选择一种权限。

相册权限校验始终结合当前用户和相册实际归属。读取权限限制图片、相册列表、统计、私有原图与缩略图；公开直链不能使携带 Token 的请求绕过其授权范围。没有 Token 的访客仍按相册直链规则访问。

上传权限按实际目标相册检查，未提供 `album_id` 时使用当前默认相册；默认相册未授权则拒绝，不能自动转入其他相册。移动图片要求源相册有修改权限、目标相册有上传权限。混合批量删除中只要有无权图片便整体拒绝。

管理相册允许新建、重命名、设置默认、修改访问策略和删除。指定相册模式不能新建相册；连同图片删除还需该相册的删除图片权限；删除相册并转移图片还需源相册修改及目标相册上传权限。相册含历史其他上传者的图片时，Token 不能删除该相册，应通过界面处理。

管理分享仅针对已授权相册中本人图片的单图分享，图片移出范围后不能继续通过 Token 列出、创建或撤销对应分享。分享链接自身仍是独立授权，撤销 Token 不会自动撤销已经创建的分享。

Token 权限保存后立即用于后续请求，不接受未知权限、重复相册或其他用户相册。列表展示授权范围、创建人（管理入口）、身份、剩余和绝对到期时间、创建时间、上次使用及状态。上次使用记录已通过凭据和接口权限校验的请求；完整 Token 只在创建时返回一次。

固定期限、自定义日期与永久均可选择。到期、撤销或停用账号后不能继续使用，撤销保留记录；全部相册授权也不能绕过用户配额、上传限制及网络规则。

“账号安全”位于右上角账号菜单。本人改密或管理员重置密码后全部登录会话失效，但个人 Token 保留；停用账号同时撤销其 Token。不提供“撤销全部 Token”操作。

## 升级与部署

版本化迁移保留图片、密码与 Token 记录。旧普通用户 Token 保持全部本人相册仅上传权限；旧管理员 Token 撤销并保留记录。为已有账号补建默认相册，并归入原未分类图片；旧相册成员授权不再使用，旧相册分享停止访问。旧单图分享此前仅由管理员创建，保留并归入原管理员账号。

所有资源接口需要同源代理 `/api/`、`/i/`、`/si/`；`/s/*` 使用 SPA 回退。S3 Bucket 保持私有。图片和分享使用 `Cache-Control: private, no-store`，不得共享缓存；已下载副本不能撤回。

IP / Referer 规则详见 [访问控制](access.md)。应急开关仅跳过网络规则，不跳过登录和资源归属检查。


撤销后的分享支持永久删除记录，同时清理分享解锁会话，不删除原图片。用户只能操作自己的分享，管理员可管理全部。管理员可设置账号角色；不能更改自己的角色、停用或删除当前账号，必须保留启用的管理员。角色变更使目标登录会话失效，个人 Token 不获得系统管理权限。删除账号前必须清理其全部图片（含待删除）及分享记录（含已撤销）；成功后清理空相册、会话、Token 和容量预占。
